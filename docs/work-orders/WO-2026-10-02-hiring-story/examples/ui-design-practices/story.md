# UI Design Practices

I wanted hiring managers to reach representative work early. I directed the portfolio’s hierarchy, navigation and color, then reviewed the interface built by AI agents.

**My role:** Portfolio design direction and rendered review

**Scope:** rickvang.com portfolio redesign

## Designing my portfolio

I directed the rickvang.com redesign for hiring managers and design leaders, with a secondary path for consulting clients. I wanted readers to reach representative projects early and have room to read through the decisions behind the work. AI agents built the interface; I set the direction, reviewed the rendered pages and chose the revisions.

## Giving the work priority

The rendered pilot leaned toward an editorial publication, with supporting sections competing for attention. The revision put a short introduction before Selected Work, followed by a compact How I work section. Notes appeared only when there were actual authored posts, with background and contact later in the page. That order made project examples the main evidence for someone deciding whether to read further.

## Bringing back the rail

The first redesign used a dark left rail. A later pilot replaced it with a horizontal header and serif headings, but I preferred the persistent rail and rejected the serif voice. I asked for the rail to return with a lighter treatment, keeping Work, Notes, About and Contact beside the reading column. The revision used warm, light surfaces and Inter throughout, with scale, weight and spacing handling the hierarchy. A permanent column would take too much of the reading width on a phone, so the built interface changed to a compact top bar and menu drawer. The destinations stayed the same. Opening the drawer moved keyboard focus into it, and Escape closed it and returned focus to the menu.

## Reviewing color in context

The agents rendered three palettes against the same portfolio pages: the existing warm colors, a less saturated warm option and a near-neutral option. Content, typography, layout and the original orange accent stayed fixed, so the comparison showed the background alongside the work it would surround. I chose the less saturated warm option. The original orange remained for active navigation and selected emphasis, with a darker orange for small text on light surfaces.

## The built portfolio

The agents carried these choices into the shared navigation shell, homepage layout and visual styles, so the direction could be inspected in the actual portfolio at desktop and mobile widths. The design reference recorded the responsive behavior, color roles and interaction states for future changes.
