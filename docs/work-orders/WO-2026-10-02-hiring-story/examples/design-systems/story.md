# Design Systems

Teams redesigning legacy capabilities needed a more consistent starting point. I designed the platform framework as part of a shared library effort.

## A common starting point

An established company was redesigning legacy capabilities and needed more consistent design across the work. Existing patterns included redundant approaches, so part of the job was deciding what teams could reuse. I designed the platform framework as part of a collaborative effort to establish a core library and lightweight governance. The library brought reusable design decisions into a common starting point for the teams involved.

## Choosing what to reuse

We audited existing design patterns alongside user scenarios, then prioritized where to remove duplication and improve consistency. Stakeholder workshops helped us align the goals, while feedback from developers helped us understand what was feasible. Reviewing the patterns together gave us existing work to organize and refine into the library.

## Shared foundations, different density needs

The core library held reusable styles and tokens. Density needed guidance suited to the surface being designed, so we maintained a display marketing style guide alongside enterprise interface guidance. Those surfaces had different needs, even within the same system. Designers could start with shared foundations and use the density guidance that matched their surface. Keeping both sets of guidance in the system allowed reuse to accommodate those differences.

## Starting a new design from a reusable screen

We created a library of reusable screens that designers could duplicate and modify for a specific use case. A template carried an existing design into the new task, giving the designer a starting point they could adapt. We also defined patterns for onboarding, work creation and progression, asset and inventory management, and account configuration and settings. The templates provided screens to work from, while the patterns guided how users moved through recurring workflows. This gave designers reusable material at the level of a screen and the task it supported.

## Keeping the system a shared priority

Getting collaborators together and keeping the system a priority were ongoing challenges. We supported the library with documentation and incremental rollouts, and developed lightweight governance around collaborative feedback loops. I worked with early adopters to build trust in the platform framework. The documentation and feedback loops supported the team's continued work on the shared library.
