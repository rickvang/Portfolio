# Rick Vang identity assets

The selected direction is a compact, continuous-line gesture that suggests an organic R/V relationship without using a literal monogram.

- `rick-vang-mark.svg` — dark standalone mark for light surfaces
- `rick-vang-mark-reversed.svg` — light standalone mark for dark surfaces
- `rick-vang-lockup.svg` — horizontal mark and wordmark for light surfaces
- `rick-vang-lockup-reversed.svg` — horizontal mark and wordmark for dark surfaces

The lockup keeps the mark in the wordmark's cap-height zone so it reads as part of the name rather than as a separate badge.
